# Security policy

FitGPX parses untrusted binary files and archives, so parser bugs can be security bugs.

**Please report vulnerabilities privately** via GitHub's
[private vulnerability reporting](https://github.com/phil-tomlinson/fitgpx/security/advisories/new)
rather than a public issue. Include a sample file if possible. You'll get a response within a week.

Supported versions: the latest release.
