# Code of conduct

This project follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be kind, assume good intent, welcome newcomers, and keep discussion about the work. Harassment
of any kind isn't tolerated. Report problems privately to the maintainer through
[GitHub](https://github.com/phil-tomlinson); reports are handled confidentially.
